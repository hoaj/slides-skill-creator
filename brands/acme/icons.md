# Acme icons

`icon-library.js` holds an openly licensed icon set. Its source and licence are in
`licenses/README.md`. The icons' path data is unchanged.

- Inline an icon as `<svg class="deck-icon" viewBox="0 0 256 256" fill="currentColor">...</svg>`.
- Icons inherit `--text`. Tint one with `--accent` by setting `color` on the icon.
- In edit mode, click an icon to swap or remove it.

Available: arrow-right, calendar, chart-bar, chart-line, chat-circle, check-circle, clock, coins, envelope, file-text, flag, folder, gear, globe, handshake, heart, lightbulb, list-checks, magnifying-glass, map-pin, megaphone, phone, puzzle-piece, rocket, shield-check, star, target, trend-down, trend-up, users, warning.
