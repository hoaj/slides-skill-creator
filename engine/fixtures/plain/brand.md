# Plain

The Engine's hidden test Brand pack. It is not a design to ship: use it to test the Engine
and to reproduce Engine bugs with neutral content.

- **Colours:** greys only. Body, muted and accent text meet WCAG AA on all three themes.
- **Type:** the system stack in `tokens.css`. The pack has no font files.
- **Logo:** a plain square and bar in `currentColor`, so it follows each theme's text colour.
- **Icons and gradients:** none. The icon picker stays hidden.
- **Classification:** `SECRET`, `PRIVATE`, `OPEN` or none. The default is `PRIVATE`.
- **PowerPoint:** no calibration, so the export applies no vertical correction and warns.
